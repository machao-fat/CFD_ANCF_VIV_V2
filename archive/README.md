# Legacy archive policy

`machao-fat/CFD_ANCF_VIV` and the former Windows worktrees are legacy forensic sources.
They are not submodules, remotes, or build inputs for this repository.

Use the archived reports in `evidence/legacy_qualification/` first. Consult the old
repository only when a specific source hash, test result, or historical contract must
be resolved. Never use filename recency as an authority rule.
